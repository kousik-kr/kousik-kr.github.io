Research Interests

Spatial and Network Data Management

Reusable data representations, indexes, and query-processing methods for large spatio-temporal and road-network datasets.

Operator-Ready Path Query Processing

Hierarchical loopless path closures and reusable path records for composing results across different query operators.

Constrained Route Planning

Preference-aware path optimization under travel-time budgets, user requirements, and real-world network constraints.

Intelligent Transportation Systems

Data-driven approaches for mobility analytics, navigation systems, and transportation optimization.

Scalable Graph Algorithms and Indexing

Hierarchical indexing, pruning, parallel processing, and storage-aware methods for computation on massive graphs.

Time-Dependent Road Networks

Routing and optimization under time-varying travel costs, user preferences, and real-world constraints.

Current Research Projects

Hierarchical Operator-Ready Loopless Path Closure for Road-Network Query Processing

  • Developing a reusable, database-style path-closure layer that stores executable loopless path records across leaf cells and parent regions instead of optimizing only one path-query objective.
  • Precomputing boundary-to-boundary closures and compact summary-path banks, then forming operator-specific results at query time through local source/target seeds and boundary-compatible hash composition.
  • Focusing the first study on static road networks and constrained score maximization under a travel-time budget, with summary-only, closure-based, and adaptive execution modes.
  • Establishing explicit exactness boundaries while evaluating storage, precomputation cost, query time, pruning effectiveness, hierarchy depth, and summary-bank scalability.
  • Building the algorithmic and data-management foundation for later work on time-dependent networks, GPU acceleration, GIS data abstraction, learning-guided optimization, dynamic updates, and a unified path-processing system.

Learning-Guided Search Optimization for Large Road Networks

  • Investigating reinforcement learning-based approaches for reducing the search space in constrained route optimization.
  • Exploring adaptive search policies that prioritize candidate paths using graph topology, temporal characteristics, and user preferences.
  • Integrating learning-guided strategies with conventional graph search while preserving solution quality.

GPU-Accelerated Graph Algorithms for Large Road Networks

  • Studying scalable graph processing frameworks for road networks on GPU architectures.
  • Exploring parallel traversal and shortest-path computation under memory hierarchy and irregularity constraints.
  • Optimizing memory coalescing, workload balance, and warp divergence for graph workloads.

Database and Secondary-Memory Optimization for Graph Processing

  • Investigating external-memory and SQL-based approaches for scalable processing of large graph datasets.
  • Exploring index structures and storage-aware algorithms for graph query processing under memory limits.
  • Designing efficient graph representations and query execution strategies for spatio-temporal networks.
